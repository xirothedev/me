<Heading id="fast" level={2}>
  {'1. Fast'}
</Heading>

- Pages need to load as fast as possible (prefer static pages).
- Optimize [image](https://nextjs.org/docs/app/getting-started/images), [font](https://nextjs.org/docs/app/getting-started/fonts), and [script](https://nextjs.org/docs/app/guides/scripts) loading.
- Search needs to be extremely fast to load and view results.

<Heading id="readable" level={2}>
  {'2. Readable'}
</Heading>

- Be concise (make every token count).
- Avoid technical jargon and idioms.
- Optimize for skimming (good use of **bold**, _italic_, lists, headings, images, etc.).
- Keep the first-time experience simple and slowly reveal complexity.
- Ensure docs have many code examples you can copy/paste or [run](https://ui.shadcn.com/docs/registry/open-in-v0).

<Heading id="helpful" level={2}>
  {'3. Helpful'}
</Heading>

- Always document workarounds even if it’s a product gap.
- Make it easy for readers to leave feedback on docs (e.g. typos).
- [Automate checking](https://cursor.com/docs/cli/github-actions) for broken links on git pushes.
- Create [learning material](https://cursor.com/learn) with a structured curriculum.
- For any breaking change, include codemods and [migration guides](https://ai-sdk.dev/docs/migration-guides/migration-guide-5-0).

<Heading id="ai-native" level={2}>
  {'4. AI-native'}
</Heading>

- [Prefer cURL](https://x.com/karpathy/status/1914494203696177444) over "click" if possible.
- [Prefer prompts](https://posthog.com/blog/envoy-wizard-llm-agent) over tutorials.
- Add an "Ask AI" sidebar that can reference your docs pages.

- Support viewing pages as Markdown (just add `.md` [to the URL](https://cursor.com/docs/bugbot.md)).

<Heading id="localized" level={2}>
  {'7. Localized'}
</Heading>

- Don’t display `/en` in the URL by default.
- Use [server-side routing](https://nextjs.org/docs/app/api-reference/file-conventions/proxy) to serve the correct language.
- Localize static strings and docs content.

<Heading id="universal" level={2}>
  {'10. Universal'}
</Heading>

- Ship docs-as-code for libraries with [JSDoc](https://jsdoc.app/) (or as a [package](https://github.com/nuxt/nuxt/pull/31353)).
- Ship your docs as an MCP server like [Context7](https://context7.com/).
- Ship your docs with your libraries in `node_modules`.
- Ship [rules files](https://github.com/oven-sh/bun/blob/f8aed4826b9a730e31be5f8209368bfd41a52152/src/init/rule.md) (like `AGENTS.md`) with your product.
- Ship [evals](https://github.com/get-convex/convex-evals) and recommend specific models for your product.
